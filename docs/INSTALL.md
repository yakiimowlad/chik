# Как подключить ЧИК

[Скачать готовый скилл](https://chik-design-skill.yakiimowlad.chatgpt.site/chik-skill.zip).
Внутри один навык `chik`, со всеми проверками и CHIK Voice. Терминал для загрузки в приложение не нужен.

## Самое простое — начать с архива

Прикрепите ZIP в чат и напишите:

> Примени ЧИК из архива к моему проекту. Сохрани его правила и сначала изучи, что я хочу сделать.

Так можно начать работу с правилами в беседе, если приложение умеет читать архивы.
Само прикрепление файла не означает постоянную установку. Чтобы скилл оставался доступен, выберите способ ниже.

## ChatGPT

Если в аккаунте доступны Skills: **Plugins → Skills → Create → Upload from your computer**.
Загрузите готовый ZIP, дождитесь проверки и подтвердите установку. Затем выберите ЧИК через `@` или попросите применить его в задаче.

Skills доступны в поддерживаемых рабочих пространствах Business, Enterprise, Healthcare и Edu;
наличие раздела зависит от аккаунта и настроек администратора. Обычная загрузка файла в чат не добавляет новый пункт Skills.
В desktop-приложении раздел Skills также может находиться прямо в боковом меню.

## Claude

**Customize → Skills → + → Create skill → Upload a skill**. Выберите ZIP и включите ЧИК в списке.
Для работы навыков должны быть доступны инструменты выполнения кода. Названия пунктов могут отличаться по версии интерфейса.
В новой беседе напишите: «Примени ЧИК к этому сайту» — или к презентации, приложению, другому проекту.

## Codex

Попросите встроенный установщик:

> $skill-installer Установи скилл из https://github.com/yakiimowlad/chik/tree/main/skills/chik

В приложении с вложениями можно отправить ZIP и попросить установить его как локальный скилл.
Агенту нужен доступ к файлам. Если ЧИК не появился в списке, откройте новую сессию.
Вызовите `$chik` или выберите его в `/skills`.

## Через терминал — по желанию

Нужны Git и Bash на macOS/Linux:

```sh
git clone https://github.com/yakiimowlad/chik.git
cd chik
bash install.sh codex
# Для Claude Code вместо последней команды:
bash install.sh claude
```

По умолчанию устанавливается только ЧИК. Сеть после клонирования не нужна.
Установщик сохраняет прежнюю версию в резервной папке и не меняет ранее установленный Unslop.
Если отдельно нужен оригинальный скилл, добавьте `--with-unslop`.
Можно скачать [комплект с установщиком](https://chik-design-skill.yakiimowlad.chatgpt.site/chik-installer.zip)
и запустить ту же команду из распакованной папки вместо клонирования.

Пути: Codex — `~/.agents/skills/chik`, Claude Code — `~/.claude/skills/chik`.
Чтобы удалить ЧИК, уберите только эту папку. Резервные копии находятся рядом в `.chik-backup.*`.
При выключении питания / SIGKILL откат не гарантируется; проверьте резервную папку и lock вручную.
