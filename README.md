# Сделать с ИИ. Довести с ЧИК.

ЧИК — скилл для сайтов, приложений и презентаций. Он помогает агенту работать последовательнее:
найти характер проекта, выстроить композицию и типографику, проверить детали и показать, что удалось проверить.

Подходит для первого личного лендинга и для проекта с серьёзными требованиями.
Вы задаёте намерение и принимаете результат; ЧИК задаёт порядок работы.

[Скачать скилл](https://github.com/yakiimowlad/chik/releases/latest/download/chik-skill.zip) · [Сайт](https://chik-design-skill.yakiimowlad.chatgpt.site) · [Все способы установки](docs/INSTALL.md)

## Начать с архива

Скачайте ZIP, прикрепите к беседе и попросите:

> Примени ЧИК из архива к этому проекту. Сначала изучи задачу, затем проверь композицию, типографику и детали. Покажи изменения и ограничения проверки.

Если приложение читает архивы, это позволяет попробовать правила в беседе.
Для постоянной установки загрузите скилл через интерфейс приложения:

| Где работаете | Как подключить |
| --- | --- |
| ChatGPT со Skills | Plugins → Skills → Create → Upload from your computer |
| Claude | Customize → Skills → + → Create skill → Upload a skill |
| Codex | Попросите `$skill-installer` установить `skills/chik` из этого репозитория |

В ChatGPT доступность зависит от плана и рабочего пространства. В Claude навыкам нужны инструменты выполнения кода.
Прикрепить файл к обычному чату и установить постоянный навык — разные действия.
[Подробности и команды для терминала](docs/INSTALL.md).

## Что проверяет

- Композицию, типографику, ритм отступов, компоненты и иконки.
- Читаемость: APCA с учётом размера текста, WCAG отдельно.
- Состояния, клавиатуру, мобильную версию и работу публичного HTML без JavaScript.
- Движение и отклик: у эффекта должна быть понятная роль. Звук — только с разрешения.
- Текст через **CHIK Voice**: по вашему запросу, с сохранением смысла и интонации.

Скилл не заменяет исследование и человеческое решение перед запуском.
Браузерные проверки и измерения возможны только там, где у агента есть нужные инструменты;
их отсутствие нужно назвать, а не выдавать за успешный тест.

## Что устанавливается

Один скилл **ЧИК** со всеми модулями. Voice уже внутри, но готовые тексты он меняет только по вашей просьбе.
Оригинальные исходники сохранены в `upstream/`, отдельный скилл по умолчанию не добавляется.

## Структура

`skills/chik/` — готовый скилл. `website/` — исходники статического сайта.
`install.sh` — необязательная установка для Codex / Claude Code.
`scripts/build.py` собирает ZIP-файлы без сторонних Python-пакетов.
