Дизайн-система

Помогает ИИ собрать сетку, выбрать шрифты и цвета. Задаёт общие правила для кнопок, карточек и отступов.

Аа

Читаемость и доступность

Проверяет контраст, размеры текста, фокус и управление с клавиатуры. Применяет принципы Apple HIG к вашему интерфейсу.

Экраны и анимация

Адаптирует макет под телефон и крупный текст. Убирает лишнее движение и проверяет, доступен ли сайт без JavaScript.

CHIK Voice

Редактирует текст в вашем стиле: убирает воду, сохраняет смысл и интонацию. Включается только по вашей просьбе.

Установить как навык

Откройте Plugins → Skills → Create → Upload from your computer. Загрузите ZIP, дождитесь проверки и подтвердите установку. После этого выбирайте ЧИК через @.

Доступ к Skills зависит от плана и настроек рабочего пространства. В desktop-приложении раздел может быть в боковом меню.

Добавить через интерфейс

Customize → Skills → + → Create skill → Upload a skill. Выберите ZIP и включите ЧИК в списке навыков.

Нужны включённые инструменты выполнения кода.

Терминал / Claude Code

Для тех, кто работает в коде. Сначала клонируйте репозиторий:

git clone https://github.com/yakiimowlad/chik.git
cd chik
bash install.sh claude

macOS / Linux. Устанавливается только ЧИК; прежняя версия резервируется.

Попросить установить из GitHub

Отправьте встроенному установщику:

$skill-installer Установи скилл из https://github.com/yakiimowlad/chik/tree/main/skills/chik

Вызовите $chik. Если он не появился, откройте новую сессию.

Терминал
git clone https://github.com/yakiimowlad/chik.git
cd chik
bash install.sh codex

macOS / Linux. Без Git можно скачать комплект с установщиком и выполнить последнюю команду из его папки.
