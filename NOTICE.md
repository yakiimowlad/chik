# Авторство

ЧИК / CHIK — независимая адаптация **Unslop by Damir Sokolovsky** (@heydamir).
Оригинал: https://github.com/heydamir/unslop. Лицензия: **CC BY 4.0**, полный текст в LICENSE.
Неизменённые файлы оригинала сохранены в `upstream/unslop/`, ревизия — `upstream/REVISION`.

В CHIK изменены имя, описание и метаданные. Добавлены APCA, применимые принципы HIG,
система отступов и компонентов, Motion/Haptics, Sound review, No-JS, Mobile UX,
Device reference и CHIK Voice. Исходные проходы и атрибуция Unslop сохранены.
Расширения — CHIK project contributors; они не приписываются автору Unslop.
Voice редактирует существующие тексты только по разрешению автора.

Golos Text: The Golos Text Project Authors, SIL OFL 1.1; файл лицензии рядом со шрифтом
в `website/assets/fonts/`. Кириллический знак и логотип разработаны для ЧИК.
Новая графика и веб-реализация — материалы проекта CHIK; отдельная лицензия на товарный
знак не предоставляется. Это не ограничивает CC BY 4.0 оригинального Unslop или OFL шрифта.

Проект не связан с Apple, Anthropic или OpenAI. Упоминание их продуктов не означает одобрение.
